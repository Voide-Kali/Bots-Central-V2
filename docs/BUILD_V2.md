# Build and roadmap status

## Completed in MVP-1

- Backend foundation, PostgreSQL, migrations, Docker health-only stack and CI.
- Registration, email verification, authentication, sessions, rotating opaque tokens and abuse control.
- React/TypeScript/Vite web client and Device Center.
- Linux Agent, pairing, Ed25519 enrollment, fingerprint approval and Device Online heartbeat/presence.

## In progress

MVP-1 hardening and documentation/release readiness are review tracks. They are not claims about features merged after the frozen snapshot.

## Next: MVP-2 design

Security Gate, Task Engine and Lock PC require approved architecture, authorization, consent, audit and failure-mode contracts before implementation.

## Future

Remote controls, mobile, Windows Agent, Desktop Companion, signed auto-update completion, production deployment/backup/restore and other integrations remain future work. Telegram, Nmap, arbitrary shell and remote software installation are not part of V2.
